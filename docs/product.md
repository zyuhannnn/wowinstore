# 产品设计

## 用户与问题

目标用户是有香港线下购物需求、希望寻找优惠的内地女性用户。产品假设来自竞品体验、个人购物经历和非结构化交流，不包装为大样本定量研究。

1. **发现成本**：资讯分散，社交平台推荐与搜索不一定及时覆盖仍有效的优惠。
2. **理解成本**：价格、件数、会员条件、时间和地点分布在不同段落及海报中。
3. **判断成本**：知道活动规则仍不等于知道现在去是否值得，尤其是门店差异与现场库存。

一期先解决信息发现和规则理解；与活动关联的交流是补充现场信息的设计方向，当前没有真实多人社区与库存系统。

## 信息分层

| 页面 | 用户任务 | 信息与交互 |
| --- | --- | --- |
| 今日惊喜 | 快速发现感兴趣的优惠 | 封面、标题、活动日期、收藏和反馈入口 |
| 优惠详情 | 看懂条件，判断是否值得到店 | 商品范围、价格与门槛、日期、地址、活动相册、地图、情报交流 |
| 过期羊毛 | 回看近期已结束的活动 | 与进行中内容分离，支持本地收起与偏好设置 |
| 我的 | 找回关注的活动与自己的发言 | 本地收藏、情报与个人设置 |

列表不承担详情页全部信息，避免用户在发现阶段就被完整条款淹没；详情也不只是原文摘要，而是把优惠对象与条件一一对应。

## 情绪设计

日历、纸张、柔和色调和「宜·发现惊喜」共同构成轻量的日常仪式。过期活动不直接消失，而进入「过期羊毛」，以轻松的表达承接遗憾。目标是让省钱之外还有发现与分享的乐趣；效果需要后续用户验证。

## 产品取舍

- 只做手机网页，优先打通从发现到到店判断的路径。
- 不做交易、返利和支付，不承诺库存或成交。
- 先用本地交互验证收藏与交流体验，暂不承担账号和社区治理成本。
- 对事实保持保守：展示窗口不冒充商家日期，地址不凭空补齐。

## 下一轮验证

让目标用户分别阅读原始资讯和结构化详情，记录价格、条件、日期、门店查找的正确率与耗时；询问去、不去或不确定的判断依据。再验证近期到店反馈是否真的改变决策，以及用户是否愿意贡献反馈。这些是拟开展的验证，不是已获得的结果。
