# 来源与版本说明

本仓库不是原始聊天记录转储，也不是重新编造的开发历史。

## 材料依据

- 2026-10-05 通过飞书 CLI 只读读取《产品介绍》最新版本（revision 3605）与《技术文档》（revision 55）。未改动原文、分享权限或评论。
- 公开文章经过重新组织，移除内部入口和运营细节；原始正文快照在私有开发仓库保存。
- 日期规则、审核闭环、证据查阅修复来自对应的 2026-09-21 项目记录。
- 管理隧道修复来自 2026-09-30 实际执行与验证记录。
- 函数示例来自当前本地源码；公开仓库不携带原仓库全部 Git 历史，也不伪造历史提交。

## 版本冲突处理

飞书技术文档保存了较早阶段的核查说明：审核提醒当时未接通。后续 2026-09-21 验收记录已证明相关闭环完成，因此公开叙述按时间区分。同时，源码中的历史 exclude 分支仍存在，明确列入限制，不把产品目标写成全部已实现。
